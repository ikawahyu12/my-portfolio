PROJECT 01 / MOBILE & WEB DEVELOPMENT

E-PKL

Integrated Internship Attendance System

An integrated internship attendance management platform designed to connect teachers, students, and administrators through digital solutions.

ROLE

Project Manager & Developer

TECHNOLOGIES

Flutter · Dart · Laravel · Figma

01 / OVERVIEW

About the Project

E-PKL is an integrated internship attendance management application developed to support the management of internship activities through a digital platform. The project connects teachers, students, and administrators within one system, providing a more centralized approach to managing internship attendance and related activities.

02 / CONTRIBUTIONS

My Role & Contributions

As the Project Manager and Developer, I was involved in coordinating the development process as well as contributing to the technical implementation of the application.

Project Management

Coordinated the project development process and helped organize the execution of project tasks.

UI/UX Design

Designed the application's visual architecture and user interface using Figma.

Mobile Development

Developed the teacher-facing mobile application using Flutter and Dart.

Web Development

Contributed to the Admin and Student web platforms using Laravel.

03 / TECHNOLOGIES

Tools & Technologies

Flutter Dart Laravel Figma

04 / REFLECTION

What I Learned

Working on E-PKL taught me how to approach software development beyond just writing code. Taking responsibility as both Project Manager and Developer helped me understand the importance of coordination, planning, and communication throughout the development process.

This project also gave me the opportunity to explore cross-platform development, combining Flutter for mobile applications and Laravel for web platforms. It strengthened my understanding of how different technologies can work together to create an integrated system.

More importantly, I learned that building a successful application requires balancing technical implementation with the needs of its users.
