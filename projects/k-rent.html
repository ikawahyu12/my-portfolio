PROJECT 03 / MOBILE APPLICATION

K-Rent

Costume Rental Application

A mobile application concept designed to support costume rental activities through structured business processes and digital workflows.

ROLE

System Analyst & Mobile Developer

PROJECT TYPE

Mobile Application

TECHNOLOGIES

Flutter · Dart

01 / OVERVIEW

About the Project

K-Rent is a costume rental mobile application developed to represent rental business activities through a digital platform.

The project focused on understanding the rental business process and translating its operational requirements into structured application workflows.

02 / CONTRIBUTIONS

My Role & Contributions

I worked as both the System Analyst and Mobile Developer, combining business process analysis with mobile application development.

Business Process Analysis

Analyzed the costume rental business process and identified the system requirements.

System Workflow Design

Designed the rental business logic and translated operational processes into application workflows.

Mobile Development

Developed the mobile application using Flutter and Dart.

03 / TECHNOLOGIES

Tools & Technologies

Flutter Dart

04 / REFLECTION

What I Learned

Developing K-Rent helped me understand the importance of analyzing a business process before translating it into a digital solution. As a System Analyst and Mobile Developer, I had to consider how the rental process could be represented through clear and structured application workflows.

Working with Flutter and Dart also strengthened my experience in mobile application development, particularly in translating system requirements into an application.

Through this project, I learned that good software development begins with understanding how a system should work, not simply deciding what features to build.
